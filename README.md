# The bigL4 Kernel

_An experimental monolithic kernel built for...interesting...people_

bigL4 currently only support RV64GC, with Armv8 support planned.

## Documentation

See `docs/` for application binary interface (ABI) documentation, or run `cargo doc` in the project root to view code documentation.
